# Usage

## Sign up and log in

The app opens on the auth screen. Create an account (email + 8+ character password) or log in.

## Upload a document

Click **Upload doc** and pick a `.txt`, `.md`, or `.pdf`. Sage extracts the text and shows it in the sidebar with its character count.

## Ask a question

Select a document, type a question, and hit **Send**. Sage returns:

- an answer drawn from your document, and
- citations showing the exact sentences it used.

If the document doesn't answer the question, Sage says so — it never guesses.

## Summarize

Select a document and click **Summarize**. The extractive summarizer returns the most informative sentences in original order.

## Conversations

Every exchange is saved. Pick a conversation from the sidebar to review history.
